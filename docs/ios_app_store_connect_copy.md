# mallog24 App Store Connect Copy

## App name
mallog24

## Subtitle
AI 음성 녹취와 구조화 문서

## Promotional text
녹음만 올리면 구조화된 녹취 문서가 완성됩니다.

## Short description
설교, 회의, 통화 음성을 AI로 텍스트 변환하고 요약과 기록본까지 정리하는 음성 기록 앱

## Long description
mallog24는 설교, 회의, 통화 음성을 빠르게 텍스트로 변환하고, 바로 활용할 수 있는 구조화 문서로 정리해주는 AI 음성 기록 서비스입니다.

주요 기능
- 음성 파일 업로드 후 AI 기반 텍스트 변환
- 설교/회의/통화 유형에 맞춘 구조화
- 교정 텍스트 제공
- 요약 생성
- 기록본 저장
- TXT, DOCX, 클립보드 복사 지원
- 한국어/영어 처리 지원

이런 사용자에게 적합합니다
- 설교 녹취와 핵심 정리가 필요한 목회자
- 회의록 초안이 필요한 팀/PM
- 통화 내용을 정리해야 하는 실무자
- 음성 기록을 문서로 빠르게 남기고 싶은 사용자

mallog24는 사용자가 업로드한 음성을 기반으로 전사 및 정리를 수행하며, 서비스 운영에 필요한 범위 내에서 개인정보를 처리합니다. 자세한 내용은 개인정보처리방침을 참고해 주세요.
