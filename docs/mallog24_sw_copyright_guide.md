### 프로그램 내용 개요 (핵심 — 그대로 사용 가능)

아래 내용을 CROS 신청서의 "프로그램 내용 개요" 란에 입력하세요.

---

**mallog24 AI 녹취록 자동 생성 시스템**은 음성 파일을 업로드하면 AI 기반 2단계 엔진을 통해 도메인 특화 녹취록을 자동으로 생성하는 소프트웨어이다.

**[1단계 — 음성 인식 및 텍스트 변환]**  
사용자가 업로드한 음성 파일(MP3, WAV, M4A 등)을 수신하여 음성 인식 모델(Whisper)을 통해 텍스트로 변환한다. 변환 과정에서 음성 구간 감지(VAD), 화자 분리, 타임스탬프 매핑 등의 전처리를 수행한다.

**[2단계 — 도메인 특화 교정 및 구조화]**  
1단계에서 생성된 원시 텍스트에 대해 대규모 언어 모델(Gemini)을 활용한 2차 교정을 수행한다. 이 과정에서 도메인별(설교, 회의, 진료 등) 전문 용어 사전을 참조하여 오인식 용어를 교정하고, 사용 목적에 맞는 구조화된 문서 형태(주보 요약, 회의록, 진료 기록 등)로 자동 변환한다.

**[주요 기능]**
- 설교/통화/회의 등 유형별 최적화된 녹취록 생성
- 도메인 특화 전문 용어 사전을 활용한 음성인식 교정
- 구조화된 문서 출력 (TXT, DOCX)
- 설교 요약 자동 생성 (주보 활용)
- 사용자 인증 및 구독 관리 (이메일/Google/Kakao 소셜 로그인)
- 변환 이력 관리 및 내보내기

**[기술 구성]**
- 클라이언트: React Native (Android/iOS 크로스 플랫폼 모바일 앱)
- 서버: Python 기반 백엔드 API 서버
- 데이터베이스: 사용자 정보, 변환 이력, 도메인 사전 관리
- 외부 API 연동: 음성 인식 엔진(Whisper), 언어 모델(Gemini)

본 프로그램은 범용 음성인식 서비스와 달리, 특정 도메인의 전문 용어 인식 정확도를 높이고 용도에 맞는 구조화된 문서를 자동 생성하는 것을 핵심 차별점으로 한다.

### 소스코드 제출물 준비 방법

CROS에서 프로그램 등록 시 **소스코드 일부**를 제출해야 합니다.

**제출 형태**: 소스코드 앞 30페이지 + 뒤 30페이지 (총 60페이지 이내)

**준비 방법**:

1. 프로젝트의 핵심 소스코드 파일을 선정합니다.
   - 백엔드: 음성 처리 파이프라인, 도메인 사전 로직, API 라우터 등
   - 프론트엔드: 앱 메인 화면, 변환 화면, 결과 표시 화면 등

2. 선정한 파일들을 하나의 텍스트 파일로 합칩니다.
   ```bash
   # 예시: 핵심 파일들을 하나로 합치기
   cat backend/main.py backend/transcription.py backend/domain_dict.py \
       app/src/screens/ConvertScreen.js app/src/screens/ResultScreen.js \
       > mallog24_source_combined.txt
   ```

3. 앞 30페이지 + 뒤 30페이지를 PDF로 출력합니다.
   - A4 기준, 한 페이지에 약 50~60줄
   - 영업비밀이 우려되는 부분은 검정 마스킹 처리 가능

4. CROS 온라인 시스템에서 PDF 또는 HWP 파일로 업로드합니다.

> 💡 **팁**: 소스코드 전체를 제출하는 것이 아닙니다. 이 프로그램이 "실제로 존재하는 코드"임을 증명하는 용도이므로, 핵심 로직이 포함된 파일을 선별하면 됩니다.

## Part 2. CROS 온라인 등록 절차 (단계별 가이드)

### 사전 준비물 체크리스트

- [ ] **공동인증서** (구 공인인증서) — 은행/정부24 등에서 발급
- [ ] **사업자등록증** 사본 (선택, 사업체 명의 등록 시)
- [ ] **소스코드 제출물** (PDF, 60페이지 이내)
- [ ] **프로그램 내용 개요** (위 Part 1의 내용)
- [ ] **등록 수수료**: 온라인 50,000원 + 등록면허세 3,600원 = **총 53,600원**

---

### Step 1. CROS 회원가입

1. **https://www.cros.or.kr** 접속
2. 우측 상단 "회원가입" 클릭
3. 개인 회원으로 가입 (공동인증서 필요)
4. 본인인증 완료 후 로그인

---

### Step 2. 등록 신청 시작

1. 로그인 후 **"저작권 등록"** 메뉴 클릭
2. **"프로그램 등록 신청"** 선택
3. 등록 유형: **"저작권 등록 (창작연월일 등록)"** 선택

---

### Step 3. 신청서 작성

아래 순서대로 입력합니다. Part 1의 내용을 참고하세요.

**① 프로그램 기본 정보**
- 프로그램명칭(국문/영문)
- 버전
- 프로그램 유형: "응용 프로그램"
- 창작연월일: Git 최초 커밋일
- 공표여부: "공표" 선택
- 공표연월일: 웹 서비스 오픈일
- 공표국가: 대한민국
- 공표매체: 인터넷

**② 저작권자 정보**
- 성명, 주민등록번호, 주소, 국적

**③ 프로그램 내용 개요**
- Part 1에서 준비한 개요 텍스트 붙여넣기

**④ 개발 환경 정보**
- 개발 언어: JavaScript, Python
- 운영체제: Android, iOS, Linux

---

### Step 4. 소스코드 업로드

1. **"첨부파일"** 항목에서 소스코드 제출물(PDF) 업로드
2. 파일명 예시: `mallog24_v1.0.0_소스코드.pdf`

---

### Step 5. 수수료 납부

1. 온라인 등록 수수료: **50,000원** (신용카드/계좌이체)
2. 등록면허세: **3,600원** (위택스 wetax.go.kr에서 별도 납부)
   - 위택스 접속 → 신고/납부 → 등록면허세 → 납부
   - 납부 영수증을 CROS에 업로드

---

### Step 6. 신청 완료 및 대기

1. 모든 입력 완료 후 "신청" 버튼 클릭
2. 접수 확인 메일 수신
3. 심사 기간: **약 1~2주**
4. 보정 요청이 오면 해당 내용 수정 후 재제출
5. 등록 완료 시 **저작권 등록증(PDF)** 발급

---

### Step 7. 등록증 활용

등록이 완료되면:
- **초기창업패키지 신청 시** 지식재산권 가점 증빙자료로 첨부
- **사업계획서**에 "SW 저작권 등록 완료 (제C-20xx-xxxxxx호)" 기재
- **IR 발표** 시 기술력 증빙 슬라이드에 포함

## 부록. 자주 묻는 질문

**Q. 개인 명의로 등록해도 되나요?**  
A. 네. 개인사업자도 대표자 개인 명의로 등록 가능합니다. 추후 법인 전환 시 양도 등록하면 됩니다.

**Q. 소스코드가 유출되지 않나요?**  
A. 제출한 소스코드는 비공개이며 열람이 제한됩니다. 영업비밀 부분은 마스킹 처리도 가능합니다.

**Q. 오픈소스 라이브러리를 사용했는데 괜찮나요?**  
A. 네. React Native, Python 라이브러리 등 오픈소스를 활용한 것은 문제없습니다. 등록 대상은 "본인이 직접 작성한 코드"이며, 오픈소스 자체가 아닌 mallog24의 고유 코드가 보호 대상입니다.

**Q. Whisper, Gemini API를 쓰는데 괜찮나요?**  
A. 네. 외부 API를 호출하는 것은 "도구를 사용한 것"이지, 해당 API의 코드를 복제한 게 아닙니다. mallog24의 파이프라인 코드, 도메인 사전 로직, 앱 UI 코드 등이 저작권 보호 대상입니다.

**Q. 다글로, 클로바노트와 충돌하지 않나요?**  
A. 전혀 충돌하지 않습니다. 저작권은 "코드(표현)"를 보호하는 것이지 "아이디어(음성→텍스트 변환)"를 보호하는 것이 아닙니다. 동일한 기능의 서비스라도 코드가 다르면 각각 별도의 저작권을 갖습니다.

**Q. 등록 후 코드를 수정하면 어떻게 되나요?**  
A. 큰 변경이 있으면 새 버전(예: 2.0.0)으로 추가 등록할 수 있습니다. 소규모 업데이트는 기존 등록으로 충분합니다.
